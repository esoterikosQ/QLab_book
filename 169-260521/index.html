라고 하면, 가설

H0:θ=θ0vsH1:θ=θ1H_0 : \theta = \theta_0 \text{vs} H_1:\theta = \theta_1H0​:θ=θ0​vsH1​:θ=θ1​
(3)

에 대해, (1)~(3)을 만족하는 기각역 C는 크기 α\alphaα인 최량기각역이 된다.

(1) L(θ0)L(θ1)=L(θ0;x1,⋯ ,xn)L(θ1;x1,⋯ ,xn)≤k\frac{L(\theta_0)}{L(\theta_1)} = \frac{L(\theta_0; x_1, \cdots, x_n)}{L(\theta_1; x_1, \cdots, x_n)} \leq kL(θ1​)L(θ0​)​=L(θ1​;x1​,⋯,xn​)L(θ0​;x1​,⋯,xn​)​≤k, (x1,⋯ ,xn)∈C(x_1, \cdots, x_n) \in C(x1​,⋯,xn​)∈C

(2) L(θ0)L(θ1)=L(θ0;x1,⋯ ,xn)L(θ1;x1,⋯ ,xn)≥k\frac{L(\theta_0)}{L(\theta_1)} = \frac{L(\theta_0; x_1, \cdots, x_n)}{L(\theta_1; x_1, \cdots, x_n)} \geq kL(θ1​)L(θ0​)​=L(θ1​;x1​,⋯,xn​)L(θ0​;x1​,⋯,xn​)​≥k, (x1,⋯ ,xn)∉C(x_1, \cdots, x_n) \notin C(x1​,⋯,xn​)∈/C

(3) Pθ0[(X1,⋯ ,Xn)∈C]=αP_{\theta_0}\big[ (X_1, \cdots, X_n) \in C \big] = \alphaPθ0​​[(X1​,⋯,Xn​)∈C]=α

임의의 크기 α\alphaα인 기각역 A가 존재할 때, 아래와 같이 표기할 수 있고,

γϕA(θ0)=∫⋯∫AL(θ)dx=α\gamma_{\phi_A}(\theta_0) = \int \cdots \int_A L(\theta) d\boldsymbol x = \alphaγϕA​​(θ0​)=∫⋯∫A​L(θ)dx=α
(4)

A와 C는 모두 크기 α\alphaα인 기각역이다. 대립가설 θ1\theta_1θ1​ 하에서 기각역 C를 가지는 검정방법과 기각역 A를 가지는 검정방법의 검정력 차이는 아래와 같이 계산할 수 있다.

마지막 부등호 관계를 유도하는 과정은 다음과 같다.

(a) xi∈C∨xi∈Ax_i \in C \vee x_i \in Axi​∈C∨xi​∈A이면 IC−IA=1−1=0I_C - I_A = 1-1=0IC​−IA​=1−1=0이므로 적분값은 0

(b) xi∉C∨xi∉Ax_i \notin C \vee x_i \notin Axi​∈/C∨xi​∈/A이면 IC−IA=0−0=0I_C - I_A = 0-0=0IC​−IA​=0−0=0이므로 적분값은 0

(c) xi∈C∨xi∉Ax_i \in C \vee x_i \notin Axi​∈C∨xi​∈/A이면 IC−IA=1−0=1I_C - I_A = 1-0=1IC​−IA​=1−0=1이고, L(θ1)−1kL(θ0)≥0L(\theta_1) - \frac 1 k L(\theta_0) \geq 0L(θ1​)−k1​L(θ0​)≥0이므로 적분값은 ≥0\geq 0≥0

가능도함수의 부등호 관계는 네이만 피어슨 정리의 (1)번 조건으로부터 귀결된다.

(d) xi∉C∨xi∈Ax_i \notin C \vee x_i \in Axi​∈/C∨xi​∈A이면 IC−IA=0−1=−1I_C - I_A = 0-1=-1IC​−IA​=0−1=−1이고, L(θ1)−1kL(θ0)≤0L(\theta_1) - \frac 1 k L(\theta_0) \leq 0L(θ1​)−k1​L(θ0​)≤0이므로 적분값은 ≥0\geq 0≥0

따라서, 모든 경우에 적분값은 0보다 크거나 같아진다.

γϕC(θ1)−γϕA(θ1)≥0∴γϕC(θ1)≥γϕA(θ1)\gamma_{\phi_C}(\theta_1) - \gamma_{\phi_A}(\theta_1) \geq 0 \\ \therefore \gamma_{\phi_C}(\theta_1) \geq \gamma_{\phi_A}(\theta_1)γϕC​​(θ1​)−γϕA​​(θ1​)≥0∴γϕC​​(θ1​)≥γϕA​​(θ1​)

어떤 A보다도 C의 검정력이 크기 때문에 C는 정의에 따라 최강력 검정이 된다. ■\blacksquare■

S16. 지수족 분포와 충분통계량¶

Theorem 2 (지수족의 UMP)

X의 분포가 지수족에 속하는 경우, 충분통계량을 이용한 최강력검정은 균일최강력검정이 된다.

지수족 분포를 따르는 확률변수 X의 밀도함수는 다음과 같이 나타낼 수 있다.

f(x∣θ)=S(x)exp⁡(c(θ)T(x)−d(θ))f(x|\theta) = S(x)\exp(c(\theta)T(x) - d(\theta))f(x∣θ)=S(x)exp(c(θ)T(x)−d(θ))
(7)

(X1,⋯ ,Xn)∼r.s.f(x;θ)(X_1, \cdots, X_n) \overset{r.s.}{\sim} f(x; \theta)(X1​,⋯,Xn​)∼r.s.f(x;θ)일 때, 가능도함수는 다음과 같다.

L(θ∣x)=∏i=1nS(xi)exp⁡(c(θ)T(xi)−d(θ))={∏i=1nS(xi)}exp⁡(c(θ)∑i=1nT(xi)−nd(θ))\begin{aligned} L(\theta|\boldsymbol x) &= \prod_{i=1}^n S(x_i)\exp(c(\theta)T(x_i) - d(\theta))\\ &= \Big\{ \prod_{i=1}^n S(x_i) \Big\} \exp(c(\theta)\sum_{i=1}^nT(x_i) - nd(\theta)) \end{aligned}L(θ∣x)​=i=1∏n​S(xi​)exp(c(θ)T(xi​)−d(θ))={i=1∏n​S(xi​)}exp(c(θ)i=1∑n​T(xi​)−nd(θ))​
(8)

MP 검정의 기각역을 C={x;L(θ1∣x)L(θ0∣x)}C = \{x; \frac{L(\theta_1|x)}{L(\theta_0|x)}\}C={x;L(θ0​∣x)L(θ1​∣x)​}으로 정의되는데, 가능도함수를 이용하여 기각역을 표현하면 다음과 같다.

L(θ1∣x)L(θ0∣x)={∏i=1nS(xi)}exp⁡(c(θ1)∑i=1nT(xi)−nd(θ1)){∏i=1nS(xi)}exp⁡(c(θ0)∑i=1nT(xi)−nd(θ0))=exp⁡[{c(θ1)−c(θ0)}∑i=1nT(xi)−n{d(θ1)−d(θ0)}]≥k\begin{aligned} \frac{L(\theta_1|x)}{L(\theta_0|x)} &= \frac{\Big\{ \prod_{i=1}^n S(x_i) \Big\} \exp(c(\theta_1)\sum_{i=1}^nT(x_i) - nd(\theta_1))} {\Big\{ \prod_{i=1}^n S(x_i) \Big\} \exp(c(\theta_0)\sum_{i=1}^nT(x_i) - nd(\theta_0)) } \\ &= \exp\big[ \{c(\theta_1)-c(\theta_0)\}\sum_{i=1}^nT(x_i) - n\{d(\theta_1)-d(\theta_0)\}\big] \geq k \end{aligned}L(θ0​∣x)L(θ1​∣x)​​={∏i=1n​S(xi​)}exp(c(θ0​)∑i=1n​T(xi​)−nd(θ0​)){∏i=1n​S(xi​)}exp(c(θ1​)∑i=1n​T(xi​)−nd(θ1​))​=exp[{c(θ1​)−c(θ0​)}i=1∑n​T(xi​)−n{d(θ1​)−d(θ0​)}]≥k​
(9)

위의 기각역에서 x\boldsymbol xx와 무관한 부분을 우항으로 넘기면 아래와 같이 정리할 수 있다.

∑i=1nT(xi)≥k+n{d(θ1)−d(θ0)}c(θ1)−c(θ0)=k′\sum_{i = 1}^nT(x_i) \geq \frac{k + n\{d(\theta_1)-d(\theta_0)\}}{c(\theta_1)-c(\theta_0)} = k'i=1∑n​T(xi​)≥c(θ1​)−c(θ0​)k+n{d(θ1​)−d(θ0​)}​=k′
(10)

우항은 데이터와 무관하게 외생적으로 결정하는 값이기 때문에 결론적으로 최강력검정의 기각역이 모수와 무관하게 정의되므로 균일최강력검정이 된다. ■\blacksquare■
