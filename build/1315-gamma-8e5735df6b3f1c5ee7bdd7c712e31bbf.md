# 감마 분포

```{admonition} 개관
:class: tip

| 항목 | 내용 |
|------|------|
| 기호 | $X \sim \text{Gamma}(\alpha, \beta)$ |
| 모수 | $\alpha, \beta > 0$ |
| 지지집합 | $(0, \infty)$ |
| 평균 | $\dfrac{\alpha}{\beta}$ |
| 분산 | $\dfrac{\alpha}{\beta^2}$ |
| 활용 | $\alpha$번째 사건까지의 대기시간, 보험 청구액, 강수량 등 양수값 연속 데이터 |
```

### 다른 분포와의 관계
